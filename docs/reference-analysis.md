# Analiza referințelor

## CAB Service
Se recomandă studierea ritmului de intro fullscreen, logo central, bară discretă de loading, tranziția către header, responsivitate mobilă, CTA rapid și acțiuni flotante. Se evită identitatea auto, textele, imaginile și paleta originale.

## Bălănoiu Andreea
Se rețin compoziția editorială a hero-ului, fotografia cu text suprapus controlat, formele subtile, spațierea și tipografia premium. Se evită identitatea juridică, lupul și reproducerea layoutului.

## Gilded
Direcție utilă: contraste întunecate, accente aurii/metalice, titluri mari și carduri fashion-editorial. Trebuie temperată pentru a nu deveni o copie.

## Veloura
Direcție utilă: roz pudrat, nude, serif elegant, spațiere aerisită, forme moi și atmosferă caldă.

## Sinteză originală
Combinația propusă este o bază caldă nude/rose, contrast editorial controlat și micro-interacțiuni fluide, cu diferențiere cromatică discretă între Dariana și Lucia. Referințele sunt inspirație de principii, nu surse de cod sau conținut.
