# Direcție preliminară (neaprobată)

- Vizual: studio premium, feminin și calm; compoziții editoriale, forme moi, contrast discret.
- Paletă: ivory/cream, nude, roz pudrat, brun-espresso; auriul rămâne accent secundar.
- Tipografie: serif elegant pentru titluri și sans-serif foarte lizibil pentru interfață.
- Header: aerisit, compact pe mobil, cu programare ca acțiune principală.
- Intro: video fără sunet, autoplay muted, poster static și fallback accesibil; implementarea finală rămâne pentru etapa următoare.
- Hero: fotografie editorială când vor fi furnizate portrete; Dariana poate primi accent rose/lilac, Lucia accent nude/auriu.
- Mobile-first: fără scroll orizontal, butoane de minimum 44 px, conținut esențial vizibil fără animații.

Aceasta este o propunere de lucru, nu o decizie finală de design.
