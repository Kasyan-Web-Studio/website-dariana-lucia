# Dariana & Lucia — Lashes and Nails Studio

Proiect nou, independent, pentru website-ul premium al Darianei (Lash Artist) și Luciei (Nail Artist). Această versiune este Etapa 1.1: pagină temporară, inventar de materiale, analiză de conținut și structură pregătită pentru etapa următoare.

Stack: Next.js/Vinext, React, TypeScript, Tailwind CSS și Cloudflare-compatible Sites/Vite. Alegerea păstrează build-ul simplu, performant și pregătit pentru Cloudflare, fără backend în această etapă.

Nu există dependențe, fișiere sau cod copiat din vechiul proiect `website luci si iubi`.
